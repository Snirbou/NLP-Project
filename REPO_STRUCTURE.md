# Repository Structure

This document provides an overview of the directory structure and key files in the `NLP-Project` repository.

## Directory Layout

```
NLP-Project/
├── data/                  # Input texts, parsing outputs, and dictionaries
├── docs/                  # Project documentation and specifications
├── results/               # Analysis results, statistics, plots, and reports
├── src/                   # Source code for parsing and analysis
└── README.md              # Main project overview
```

## Detailed Description

### 1. `data/`
Contains all data resources used and generated by the project.
*   **input/**: Raw Hebrew text files organized by corpus (Biblical, Rabbinic, Modern).
*   **output/**: Parsed JSON files generated by the DictaBERT pipeline, mirroring the input structure.
*   **dictionaries/** (if applicable): Auxiliary lexical resources.

### 2. `docs/`
Documentation files describing the project goals, architecture, and background.
*   `project_description.txt`: Original project requirements and research questions.
*   `PROJECT_ARCHITECTURE.md`: Technical architecture and data flow documentation.
*   `classifier_info.txt`: Information regarding the classification models.
*   `work-plan.pdf`: Detailed work plan and academic background.

### 3. `results/`
Outputs from the analysis scripts.
*   **CSVs**: Feature tables (`all_sentences_features.csv`) and aggregated statistics (`layer2_stats/`).
*   **Plots**: Visualizations of syntactic trends (`plots/`).
*   **Reports**: Final research report (`FINAL_RESEARCH_REPORT.md`) and classification metrics.

### 4. `src/`
Python source code divided into two main modules:

#### `src/dictaParsing/`
Scripts for the initial text processing pipeline.
*   `dicta_batch_parser.py`: Interface with the DictaBERT model for morphological and syntactic analysis.
*   `batch_run_recursive.py`: Driver script to recursively process input directories.

#### `src/analysis/`
Scripts for feature extraction, statistical analysis, and machine learning.
*   `extract_features.py`: Extracts linguistic features from parsed JSONs into a tabular format.
*   `generate_stats.py`: Aggregates features and computes corpus-level statistics.
*   `classify_sentences.py`: Trains and evaluates classifiers to distinguish between corpora.
*   `plot_results.py`: Generates visualization plots from statistics.
*   `style_transfer_analysis.py`: Experimental analysis of style transfer capabilities.
