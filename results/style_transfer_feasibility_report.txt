Style Transfer & Edit Distance Analysis
=======================================
Date: [Current Date]

Objective
---------
Measure the "stylistic distance" between Modern Hebrew and Biblical/Rabbinic Hebrew by using a generative LLM (DictaLM 2.0 Instruct) to rewrite sentences and calculating the edit distance (Levenshtein) required for the transformation.

Methodology
-----------
1.  **Input**: 50 random sentences from the "Haaretz" (News) corpus.
2.  **Model**: `dicta-il/dictalm2.0-instruct` (7B parameter model).
3.  **Task**:
    *   Prompt 1: "Rewrite this Modern Hebrew sentence into Biblical Hebrew."
    *   Prompt 2: "Rewrite this Modern Hebrew sentence into Rabbinic Hebrew."
4.  **Metric**: Normalized Levenshtein Distance (0 = identical, 1 = completely different).

Status & Feasibility
--------------------
**Current Status**: The code is fully implemented in `src/analysis/style_transfer_analysis.py`.
**Execution**: The model (`dicta-il/dictalm2.0-instruct`) is a 7B parameter Large Language Model. Running this requires approximately **16GB of VRAM (GPU)** or **32GB of RAM (CPU)** to load comfortably.
**Attempt**: We attempted to run this locally, but the process was interrupted/cancelled likely due to the massive download size (~14GB) and memory constraints of the current environment.

Recommendation
--------------
To complete this analysis, the script `NLP-Project/NLP-Project/src/analysis/style_transfer_analysis.py` should be run on a machine with a GPU (e.g., Google Colab Pro or a local machine with CUDA support). The input file `NLP-Project/data/style_transfer_input_50.json` is already prepared.

---------------------------
If `Average_Distance(Modern -> Biblical) < Average_Distance(Modern -> Rabbinic)`, it would support Doron's hypothesis that Modern Hebrew structure is closer to Biblical Hebrew (requiring fewer edits to convert).
