# Repository Structure

This document provides an overview of the directory structure and key files in the `NLP-Project` repository.

## Directory Layout

```
NLP-Project/
├── data/                  # Input texts, parsing outputs, and dictionaries
├── docs/                  # Project documentation and specifications
├── results/               # Analysis results, statistics, plots, and reports
├── src/                   # Source code for parsing and analysis
└── README.md              # Main project overview
```

## Detailed Description

### 1. `data/`
Contains all data resources used and generated by the project.
*   **input/**: Raw Hebrew text files organized by corpus (Biblical, Rabbinic, Modern).
*   **output/**: Parsed JSON files generated by the DictaBERT pipeline, mirroring the input structure.
*   **dictionaries/** (if applicable): Auxiliary lexical resources.

### 2. `docs/`
Documentation files describing the project goals, architecture, and background, organized by language.

#### `docs/english/`
*   `project_description.txt`: Original project requirements and research questions (Translated).
*   `PROJECT_ARCHITECTURE.md`: Technical architecture and data flow documentation (Translated).
*   `classifier_info.txt`: Information regarding the classification models (Translated).
*   `REPO_STRUCTURE.md`: This file.

#### `docs/hebrew/`
*   `project_description.txt`: Original project requirements (Original).
*   `PROJECT_ARCHITECTURE.md`: Technical architecture (Original).
*   `classifier_info.txt`: Classifier info (Original).
*   `work-plan.pdf`: Detailed work plan and academic background.

### 3. `results/`
Outputs from the analysis scripts, organized by content type:

#### `results/reports/`
Organized by language. Contains the final findings and summaries.
*   **english/**: `MANUAL_CLASSIFIER_REPORT.md`, `DICTABERT_ANALYSIS.md`, `STYLE_TRANSFER_REPORT.md`, `HUMAN_EVALUATION_REPORT.md`.
*   **hebrew/**: `FINAL_RESEARCH_REPORT.md`, `STYLE_TRANSFER_REPORT.md`, `HUMAN_EVALUATION_POLL.pdf`.

#### `results/raw_data/`
*   `all_sentences_features.csv`: The master table containing all extracted features per sentence.

#### `results/aggregated_stats/`
*   CSVs containing high-level corpus statistics (e.g., `word_order_v1_v2_stats.csv`, `subordination_words_stats.csv`).

#### `results/classification_data/`
*   Raw CSV outputs and metrics from the classification models (`classifiers_comparison.csv`, predictions).

#### `results/style_transfer_data/`
*   JSON results and raw output from the generative style transfer experiments.

#### `results/plots/`
*   Visualizations of syntactic trends (PNG images).

### 4. `src/`
Python source code divided into two main modules:

#### `src/dictaParsing/`
Scripts for the initial text processing pipeline.
*   `dicta_batch_parser.py`: Interface with the DictaBERT model for morphological and syntactic analysis.
*   `batch_run_recursive.py`: Driver script to recursively process input directories.

#### `src/analysis/`
Scripts for feature extraction, statistical analysis, and machine learning.
*   `extract_features.py`: Extracts linguistic features from parsed JSONs into a tabular format.
*   `generate_stats.py`: Aggregates features and computes corpus-level statistics.
*   `classify_sentences.py`: Trains and evaluates classifiers to distinguish between corpora.
*   `plot_results.py`: Generates visualization plots from statistics.
*   `style_transfer_analysis.py`: Experimental analysis of style transfer capabilities.

#### `src/analysis/perplexity/`
Scripts for the N-gram Perplexity Analysis.
*   `main.py`: Orchestrator for the perplexity pipeline.
*   `calculate_perplexity.py`: Implementation of Lidstone-smoothed N-gram models.
*   `data_loader.py`: Utilities for loading and processing JSON corpus data.
